# Lesson 40

Материалы по продвинутому Terraform/OpenTofu:

- `mods/` - пример модуля и его использования
- `infra-pipelines/` - пример Terraform + Ansible пайплайна
- `tofu/` - пример шифрования state в OpenTofu
- `ws/` - дополнительные эксперименты

В файлах есть демонстрационные значения подсетей и образов, их нужно заменить под своё окружение.
