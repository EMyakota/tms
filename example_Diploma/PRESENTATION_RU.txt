Мой дипломный проект - это DevOps-обвязка для публичного приложения на Go.
Я взял открытый репозиторий как основу и доработал его до полноценного сервиса.

Что было сделано:

добавлены API endpoints, healthcheck, readiness check и метрики для Prometheus;
добавлена контейнеризация через Docker;
собрана локальная инфраструктура через docker-compose;
настроен мониторинг через Prometheus и Grafana;
добавлен CI/CD через GitHub Actions;
подготовлен Terraform-слой для автоматизированного запуска.

В результате проект соответствует основным требованиям диплома:
есть публичная кодовая база, автоматизация развертывания, CI/CD, мониторинг и документация для запуска и демонстрации.
