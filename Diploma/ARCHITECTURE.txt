Как устроен дипломный проект.

Есть три основные части.

Первая часть - приложение.
Это Go-сервис, который отвечает по HTTP и отдает метрики.

Вторая часть - окружение.
Через docker-compose поднимаются:

- само приложение
- Prometheus
- Grafana

Третья часть - автоматизация.
В проекте есть:

- GitHub Actions для CI/CD
- Terraform для автоматизированного старта инфраструктуры
- PowerShell-скрипты для локального запуска и остановки

Как работает поток:

1. Код меняется и отправляется в репозиторий.
2. GitHub Actions запускает проверки и сборку.
3. При работе с основной веткой может выполняться deployment.
4. Приложение отдает метрики в Prometheus.
5. Grafana читает данные из Prometheus и показывает их на dashboard.
