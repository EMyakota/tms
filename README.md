# TMS homework

Домашние задания собраны по урокам `L38`-`L46`.

- `L38-L42` - Terraform / OpenTofu / Packer / IaC-практика
- `L43-L46` - Kubernetes манифесты и примеры
- `Diploma` - дипломный DevOps-проект с приложением, CI/CD и мониторингом

В Terraform-конфигурациях секреты и локальные пути вынесены в переменные или примеры `terraform.tfvars.example`.
Реальные значения перед запуском нужно подставить под свой аккаунт AWS/Yandex Cloud и свою локальную среду.
Для удобства проверки в каждой папке есть описание и краткий отчет по выполнению.
