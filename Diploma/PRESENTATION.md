# Diploma Presentation Notes

## Project

Diploma project demonstrates a full DevOps pipeline for a public Go application:

- source code based on a public repository
- automated build and delivery
- declarative infrastructure
- application monitoring

## Tools

- Go
- Docker / Docker Compose
- Terraform
- GitHub Actions
- Prometheus
- Grafana
- Telegram notifications

## Result

- local environment can be started with one command
- each commit runs CI checks
- pushes to `main/master` can trigger deployment
- app and infrastructure are observable through monitoring stack
